# console/

Code für die Konsole selbst (Hauptgerät) – das Kernstück des Projekts,
im Stil einer Xbox: schließt an den Fernseher an und wird mit normalen
Controllern gesteuert.

## Enthält
- `firmware/` – Betriebssystem-nahe Sachen (Boot, Treiber, Grundkonfiguration)
- `menu-ui/` – Unity-Projekt für das Konsolen-Menü/Dashboard
- `docs/` – Hardware-Pläne, Schaltpläne, Notizen zu diesem Teil
