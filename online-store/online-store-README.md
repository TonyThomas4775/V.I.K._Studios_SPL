# online-store/

Backend und Webseite für den eigenen Online-Store, über den Spiele/Apps
für die Konsole vertrieben werden.

## Enthält
- `backend/` – API (z.B. FastAPI oder ASP.NET Core)
- `frontend/` – Store-Webseite
- `docs/` – Notizen zu diesem Teil
