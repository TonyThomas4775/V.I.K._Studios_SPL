# controller/

Firmware für die normalen Controller (kein Motion-Controller wie bei der
Wii, sondern klassisches Gamepad-Layout ähnlich einem Xbox-Controller).

## Enthält
- `firmware/` – Code für den Mikrocontroller (z.B. ESP32, Arduino/PlatformIO-Projekt)
- `docs/` – Belegungspläne, Schaltpläne, Notizen zu diesem Teil
